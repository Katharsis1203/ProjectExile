AVATAR ASSET GUIDE

The files in demo/ are temporary placeholder SVGs created only to demonstrate the layered avatar system.
They are not sourced from the game's existing artwork and are not intended as final art.

Replace them with your own transparent PNG/WebP/SVG layers while keeping every layer on the same canvas,
with the same pose, framing, and alignment.

Recommended conceptual stack:
  base -> skin -> tattoo/scar -> underclothes -> clothing -> armour -> outerwear -> hair -> accessory/headgear -> condition

The active demo layer list is configured in:
  src/data/defaultAvatar.ts
